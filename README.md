# WordPress Version Checker

Инструмент для проверки версий WordPress и PHP на различных сайтах.

## Функции

- ✅ Определение версии WordPress
- ✅ Определение версии PHP
- ✅ Проверка SSL-сертификатов
- ✅ Рекомендации по обновлениям
- ✅ Массовая проверка сайтов
- ✅ Экспорт результатов (JSON, CSV)
- ✅ Кэширование результатов

## Использование

1. Введите URL'ы сайтов (по одному в строке)
2. Или загрузите файл со списком URL
3. Нажмите "Начать проверку"
4. Просмотрите результаты и рекомендации

## Требования

- PHP 7.4+
- cURL расширение
- Права на запись в директории cache/ и logs/

## Безопасность

- Rate limiting для предотвращения злоупотреблений
- Проверка IP-адресов
- Защита конфиденциальных файлов
- Ограничение количества URL за проверку
